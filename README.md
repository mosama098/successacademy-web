# Success Academy Website

Professional bilingual Arabic/English marketing funnel for Success Academy English courses.

## Scope

- Landing pages at `/ar` and `/en`
- Arabic RTL and English LTR support
- Booking CTA placeholders for assessment appointments
- WhatsApp CTA placeholder
- No internal exam, CRM, LMS, TMS, portals, or detailed pricing tables

## Development

```bash
npm install
npm run dev
```

## Production check

```bash
npm run build
```
